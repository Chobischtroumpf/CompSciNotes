# A*
A* combines features of Dijkstra's Algorithm and Greedy Best-First-Search, making it both accurate and efficient:

1. $g(n)$: This is the actual cost from the start node to any node n. It reflects the path length, energy cost, or any metric that measures the distance from the start.
2. $h(n)$: This is the heuristic estimated cost from node n to the goal. It’s an educated guess used to influence the order of node exploration towards the destination.
3. $f(n) = g(n) + h(n)$: This function evaluates the total estimated cost of the cheapest solution through n. Nodes with lower f values are prioritized in the search process.
## Why Heuristics?
The heuristic function $h(n)$ is crucial because it helps A* to focus its search direction towards the goal rather than exploring in multiple directions equally. The choice of heuristic affects the efficiency and completeness of the algorithm:

- **Admissible Heuristic**: This is optimistic and never overestimates the true cost to reach the nearest goal. It guarantees that A* will find an optimal path if one exists.
- **Consistent Heuristic (or Monotonic)**: This not only satisfies the admissible condition but also ensures the cost estimation is always increasing along the path.
## Manhattan Distance as a Heuristic
The Manhattan distance is a popular heuristic for grid-based games or problems where movements are restricted to horizontal and vertical (like a taxicab geometry). Here's why it's used:

- It calculates the total number of steps moved horizontally and vertically to reach the target from the current position without considering diagonal moves.
- It's effective in a grid where you can only move up, down, left, or right (no diagonal moves).
- It's both admissible and consistent in such environments, ensuring optimal pathfinding.
## Pseudo-code of the A* Algorithm
```C
function A*(start, goal)
    // The set of discovered nodes that may need to be (re-)expanded.
    openSet = {start}

    // For node n, gScore[n] is the cost of the cheapest path from start to n currently known.
    gScore[start] = 0

    // For node n, fScore[n] = gScore[n] + h(n).
    fScore[start] = h(start)

    while openSet is not empty
        current = node in openSet with the lowest fScore[current]

        if current == goal
            return reconstruct_path(current)

        openSet.remove(current)

        for each neighbor of current
            // d(current,neighbor) is the weight of the edge from current to neighbor
            // tentative_gScore is the distance from start to the neighbor through current
            tentative_gScore = gScore[current] + d(current, neighbor)

            if tentative_gScore < gScore[neighbor]
                // This path to neighbor is better than any previous one. Record it!
                cameFrom[neighbor] = current
                gScore[neighbor] = tentative_gScore
                fScore[neighbor] = gScore[neighbor] + h(neighbor)

                if neighbor not in openSet
                    openSet.add(neighbor)

    // Open set is empty but goal was never reached
    return failure
```
# Pythagorean Triples
```python
from Blueprints.Data_Structures.Heap import MinHeap

def alpha(a, b, c):
    return a - 2 * b + 2 * c, 2 * a - b + 2 * c, 2 * a - 2 * b + 3 * c


def beta(a, b, c):
    return 2 * a + b + 2 * c, a + 2 * b + 2 * c, 2 * a + 2 * b + 3 * c


def gamma(a, b, c):
    return -2 * a + b + 2 * c, -a + 2 * b + 2 * c, -2 * a + 2 * b + 3 * c

def triples(n):
    root = (3, 4, 5)

    heap = MinHeap()
    heap.insert(root)

    seen = set()
    seen.add(root)

    while heap.array:
        triplet = heap.delete()

        if triplet[2] > n:
            continue
		yield triplet

        for f in (alpha, beta, gamma):
            new = f(*triplet)

            if new not in seen and new[2] <= n:
                seen.add(new)
                heap.insert(new)
    return
```
## Time Complexity
The `triples` function uses a priority queue (min-heap) and explores new triplets generated by the functions `alpha`, `beta`, and `gamma`. The complexity is driven by the number of unique triplets generated and processed.

1. **Heap Operations**: Each triplet insertion and extraction from the heap takes $O(\log k)$, where $k$ is the number of elements in the heap.
2. **Triplet Generation**: For each triplet extracted from the heap, three new triplets are generated.
3. **Seen Set Check**: Checking if a triplet is in the set `seen` takes $O(1)$ on average.

Given `n` as the upper bound for the triplet's third element (`triplet[2]`), the number of unique triplets `T(n)` depends on the nature of the transformation functions. In general, each function (`alpha`, `beta`, `gamma`) generates triplets with increasing values. The growth rate can be approximated by the rate at which the smallest value triplet can reach the upper bound `n`.

Let $m$ be the number of triplets generated and processed before all valid triplets are exhausted:

- Each triplet generates 3 new triplets, but only unique triplets are added to the heap.
- In the worst case, we can consider the relationship and constraints leading to a logarithmic growth of triplets due to repeated applications of the transformation functions.

The overall time complexity can be approximated by:
$$O(m \log m)$$
where $m$ is the number of unique triplets generated, which grows polynomially with respect to `n`.

Therefore, the time complexity in the worst case can be approximated by:
$$O(n^k \log n^k) \approx O(n^k \log n)$$
for some constant $k$.
## Space Complexity
The space complexity is determined by the space needed to store the heap and the set of seen triplets:

1. **Heap**: At most, the heap will contain all unique triplets that are less than or equal to `n` in the third element.
2. **Seen Set**: This will also store the same number of unique triplets as the heap.

Since the number of unique triplets grows polynomially with `n`, the space complexity is:
$$O(m) \approx O(n^k)$$
## Summary
- **Time Complexity**: $O(n^k \log n)$ where $k$ is a constant related to the rate of growth of unique triplets.
- **Space Complexity**: $O(n^k)$ where $k$ is the same constant as above.
