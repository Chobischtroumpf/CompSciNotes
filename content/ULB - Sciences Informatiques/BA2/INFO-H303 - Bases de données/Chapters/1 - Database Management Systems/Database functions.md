> [!info]
> A **database** performs several key functions to manage [[ULB - Sciences Informatiques/BA2/INFO-H303 - Bases de données/Chapters/1 - Database Management Systems/Data#^493a3b|data]] efficiently:
> - **Structure Definition** – Defines [[Database#^fedb9b|database]] [[Database schema#^ae34f4|schema]], tables, attributes, and constraints (e.g., declaring `Student(StudName, StudentNo, Class, Dept)`).
> - **Population** – Inserts initial and ongoing [[ULB - Sciences Informatiques/BA2/INFO-H303 - Bases de données/Chapters/1 - Database Management Systems/Data#^493a3b|data]] (e.g., adding students, courses, and prerequisites).
> - **Querying** – Retrieves specific [[ULB - Sciences Informatiques/BA2/INFO-H303 - Bases de données/Chapters/1 - Database Management Systems/Data#^493a3b|data]] based on user requests (e.g., listing prerequisites for a course, filtering students by grades).
> - **Reporting** – Generates structured outputs (e.g., diplomas with student names, courses, grades).
> - **Modification (Data Updates)** – Updates existing [[ULB - Sciences Informatiques/BA2/INFO-H303 - Bases de données/Chapters/1 - Database Management Systems/Data#^493a3b|data]] (e.g., adding a new course session, recording grades).
> - **Schema Modification** – Alters [[Database#^fedb9b|database]] structure (e.g., adding new relations like `Instructors`, modifying attributes like `Student.Address`).
