> [!info]+ Definition
> A **Database Management System (DBMS)** is a collection of general-purpose, application-independent programs that provide essential services for managing [[Database#^fedb9b|databases]].

^4c30d6

These services include:
- **Defining the database structure** – Specifying [[ULB - Sciences Informatiques/BA2/INFO-H303 - Bases de données/Chapters/1 - Database Management Systems/Data#^493a3b|data]] types and constraints.
- **Data storage management** – Ensuring safe, long-term storage on controlled media.
- **Data manipulation** – Allowing efficient querying, updates, and report generation.
- **User and access management** – Controlling user rights and security.
- **Performance optimization** – Enhancing efficiency and resource utilization.
- **Data sharing** – Facilitating multi-user access and concurrent operations.
- **Security and reliability** – Protecting [[ULB - Sciences Informatiques/BA2/INFO-H303 - Bases de données/Chapters/1 - Database Management Systems/Data#^493a3b|data]] from unauthorized access and accidental loss.
- **Monitoring and analysis** – Tracking [[Database#^fedb9b|database]] usage and optimizing performance.

> [!note]
> DBMS have similarities with operating systems: both manage memory, process scheduling, I/O, communication.

> [!note]
> They also implement many data-management functions and typically do not use the file system of the operating system of the machine where they are installed. Instead, the define their own richer file organizations and access methods.
