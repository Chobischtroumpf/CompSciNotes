> [!info]+ Definition (Entity Type)
> An **entity class** defines a **concept, type, or prototype** that groups similar entities. It represents both:
> - **Intension** – The conceptual definition or structure of the entity (e.g., a `Student` entity type with attributes like `StudentNo`, `Name`, and `Class`).
> - **Extension** – The collection of actual **instances** of that entity (e.g., individual students in the `Student` table).

> [!info]+ Instance
> An **instance** of an entity is a **specific occurrence** of that entity class, with unique attribute values (e.g., `StudentNo = 123`, `Name = Alice`).
