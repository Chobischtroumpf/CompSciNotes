> [!info]+ Définition
> Un **code univoque** ou **décodable** est un code pour lequel la [[Fonction de codage#^0a7213|fonction de codage]] étendue est inversible. Cela signifie qu'il n'y a **pas de perte d'information** lors du codage: chaque message peut être uniquement décodé.

^95f169

> [!abstract]- Propriété fondamentale
> Pour qu'un code soit univoque, la fonction de codage étendue doit être bijective:
> $$K : S^* \to K(S^*) \text{ est bijective}$$

- Un code est univoque si et seulement si aucune séquence de symboles ne peut être codée de deux manières différentes, même en considérant toutes les combinaisons possibles de mots du code.
