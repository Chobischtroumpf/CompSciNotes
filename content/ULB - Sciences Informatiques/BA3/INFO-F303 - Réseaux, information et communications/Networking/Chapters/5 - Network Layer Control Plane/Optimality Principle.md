---
title: Optimality Principle
authors: Mihai Bors
tags:
  - Network
---
If a router J is on the optimal path from router I to router K, then the optimal path from J to K also falls along the same route

Consequence: the set of optimal paths from a source to all destinations form a tree rooted at the source
