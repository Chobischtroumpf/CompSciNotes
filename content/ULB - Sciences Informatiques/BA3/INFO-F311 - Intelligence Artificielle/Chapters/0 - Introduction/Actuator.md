> [!info]+ Definition
> An **actuator** is a component that allows an agent to act and make changes in its environment.

> [!example]+ Examples
> - Motors
> - Speakers
> - Displays
> - Robotic arms
> - Network interfaces

> [!note]+ Related Concepts
> - **[[Agent]]**: Entity using actuators
> - **[[Sensor]]**: Counterpart for perceiving
> - **[[Planning Agent]]**: Uses actuators to execute plans
