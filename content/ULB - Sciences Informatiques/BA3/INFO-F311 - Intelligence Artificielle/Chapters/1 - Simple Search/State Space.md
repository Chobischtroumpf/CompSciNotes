> [!info]+ Definition
> The **state space** is the set of all possible [[Search State|search states]] ([[World State|world states]]) that represent the essential information needed to solve a specific problem.

> [!note]+ Related Concepts
> - **[[Search State]]**: Individual state in the space
> - **[[World State]]**: Complete environment description
> - **[[Search Problem]]**: Problem using state space
> - **[[State Space Graph]]**: Graph representation of state space
