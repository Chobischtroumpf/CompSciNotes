> [!info]+ Définition
> L'**informatique fondamentale** est une branche de l'informatique dont le principal but est la conception de modèles pour des problèmes, concepts ou applications informatiques, et le développement d'algorithmes pour analyser ces modèles.

## Objectifs Principaux

> [!abstract]+ Axes de Recherche
> L'informatique fondamentale se concentre sur :
>
> 1. **Modélisation** : Créer des représentations abstraites de problèmes réels
> 2. **Analyse** : Développer des méthodes pour étudier ces modèles
> 3. **Classification** : Organiser les problèmes selon leur complexité intrinsèque
> 4. **Compréhension théorique** : Établir les limites fondamentales du calcul

## Modèles Étudiés

> [!example]+ Exemples de Modèles
> **[[Graphe]]** :
> - Modèles de réseaux (sociaux, routiers, web)
> - Modèles de dépendances
>
> **[[Logique]]** :
> - Modélise les énoncés mathématiques
> - Modélise les propriétés de systèmes
>
> **[[Système de Déduction]]** :
> - Modélise le raisonnement mathématique via la notion de preuve
>
> **[[Machine de Turing]]** :
> - Modèle de calcul
>
> **[[Automate]]** :
> - Modélise des programmes informatiques "simples"
>
> **[[Chaîne de Markov]]** :
> - Modélise des systèmes probabilistes
